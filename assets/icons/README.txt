Custom admin icons for Stock Order Plugin

Drop these PNG files into this folder (exact filenames):

- supplier.png   (Supplier card icon)
- container.png  (Container/CBM card icon)
- rounding.png   (Rounding controls card icon)

Recommended:
- square PNG (64x64 or 128x128)
- transparent background
- simple bold shapes for clarity at small sizes

The Pre-Order screen will automatically embed these icons from disk as CSS data URIs (no HTTP request needed).
